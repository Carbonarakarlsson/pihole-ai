# PiHole-AI Branding

Official project logo assets.

- `logo-dark.png`: primary logo
- `logo-light.png`: light-background presentation
- `logo-transparent.png`: transparent-background logo
- `icon.png`: transparent square icon
- `github-avatar-1024.png`: GitHub avatar
- `favicon.ico` and fixed-size PNGs: browser/app icons
- `logo.svg` and `icon.svg`: SVG containers embedding the approved artwork

The SVG files preserve the artwork exactly; they are not hand-traced vector paths.
